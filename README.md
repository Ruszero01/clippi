# Clippi - 剪贴板管理器

![Banner](assets/Banner.png)

一个轻量级剪贴板管理器，使用 Rust + Slint 构建。支持 Windows 和 macOS。

## 功能

### 剪贴板监控
- 自动监听系统剪贴板变化，实时记录历史
- 多格式内容检测：
  - **纯文本** — 普通文本内容
  - **富文本** — HTML、RTF 格式
  - **图片** — PNG 格式，支持透明通道
  - **链接** — URL 自动识别，支持域名/路径提取、favicon 预览
  - **文件** — 文件/文件夹路径，支持多文件批量，提取系统图标
  - **路径** — 本地路径智能识别
  - **颜色** — HEX/RGB 颜色自动检测，支持多种格式 (#RGB, #RRGGBB, rgb/rgba)
- 内容去重：相同内容重复复制时更新时间戳，不重复记录
- 颜色去重归一化：不同格式的相同颜色 (如 `#FF8000` 和 `rgb(255,128,0)`) 视为重复
- SQLite 本地持久化存储

### 内容管理
- 双击卡片快速粘贴到上一个活动窗口
- 单击复制内容到剪贴板
- 卡片悬浮工具栏：收藏、复制、删除
- 右键菜单：粘贴为 RGB / 粘贴为 HEX (颜色)、复制、粘贴、收藏、删除
- 按类型筛选：文本 / 格式 / 图片 / 文件 / 链接 / 颜色
- 关键词搜索
- 收藏夹筛选
- 自定义排序：按创建时间或最后使用时间
- 多选批量操作：批量粘贴、批量收藏、批量删除
- 备注编辑
- 全内容编辑

### 窗口与交互
- 全局快捷键呼出/隐藏窗口（默认 Alt+V，可自定义）
- 窗口固定（置顶）模式
- 失焦自动隐藏
- 多显示器支持
- 三种窗口位置模式：居中 / 跟随鼠标 / 记住位置
- 可拖拽边框调整窗口大小

### 显示选项
- 来源应用信息显示（剪贴板来源程序名称和图标）
- 链接 favicon 网站图标预览
- 文件/路径类型系统图标
- 自动滚动到顶部（粘贴后）
- 悬停显示原始内容
- 纯文本复制模式

### 设置
- 暗色 / 亮色 / 跟随系统 三种主题
- 开机自启动（Windows 注册表 / macOS LaunchAgent）
- 静默启动（启动后隐藏窗口）
- 快捷键录制自定义
- 卡片高度模式：高 / 中 / 低 / 自动
- 数据库路径自定义与迁移

### 系统集成
- 系统托盘常驻后台运行
- 托盘右键菜单：显示窗口、设置、退出
- 双击托盘图标呼出窗口

## 技术栈

| 组件 | 技术 |
|------|------|
| UI 框架 | [Slint](https://slint.dev/) 1.15 |
| 剪贴板 | clipboard-rs |
| 数据存储 | rusqlite (bundled SQLite) |
| 系统托盘 | tray-icon |
| 全局快捷键 | global-hotkey |
| 图片处理 | image |
| HTTP | ureq (favicon 获取) |
| 系统API | windows-sys / objc2-app-kit |

## 构建

```bash
cargo build
cargo run
```
